# Samples Policy — سياسة العينات

## القاعدة الذهبية

**ممنوع منعاً باتاً ارتكاز (commit) أي مستند أعمال حقيقي في هذا المستودع** — فواتير، كشوفات، عقود، أو أي PDF يحمل بيانات تجارية أو شخصية حقيقية. (السوابق: حذف «فاتورة رقم 000005» في PR #1.)

## العينة المسموحة

العينة المرجعية لتصميم الطباعة (فاتورة ZATCA الثنائية A4) يجب أن تكون:

1. **ببيانات وهمية بالكامل** — بائع: «شركة النموذج التجريبية للتجارة»، رقم ضريبي `300000000000003`، سجل تجاري `1010999999`، مشتري: «عميل تجريبي»، رقم فاتورة `SAMPLE-000001`.
2. **بعلامة مائية** «عينة تجريبية — SAMPLE» قطرياً على كل صفحة.
3. **مخزنة هنا فقط** في `docs/samples/` — وCI يرفض أي `*.pdf` خارج هذا المجلد.

## كيف تنتج العينة الآن (يدوياً — نفس القالب الإنتاجي بالضبط)

1. شغّل بيئة staging المحلية (`supabase start && pnpm dev`) مع بيانات seed.
2. أنشئ فاتورة من حساب المستأجر التجريبي بالبيانات الوهمية أعلاه، ثم صدّرها PDF من واجهة الفواتير (نفس مسار الطباعة الإنتاجي).
3. أضف العلامة المائية، ثم احفظ الملف باسم `docs/samples/invoice-sample.pdf` (استهدف < 150KB).

أنشئ `scripts/generate-sample-invoice.ts` يستورد **نفس** مولّد المستندات الإنتاجي (راجع `src/lib/templates/document-html.ts` و`src/lib/templates/generator.ts` وقالب فاتورة ZATCA من commit `8dc4339`) مع fixture وهمي + العلامة المائية، وأضف `"sample:invoice": "tsx scripts/generate-sample-invoice.ts"` إلى package.json. أعد توليد العينة بعد أي تعديل على القالب.
